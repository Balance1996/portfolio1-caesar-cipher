# Caesar Cipher Project

This project implements a Caesar Cipher encryption and decryption system in Python.

The Caesar Cipher works by shifting each letter in the alphabet by a fixed number of positions. For example, a shift of 3 turns "A" into "D".

## How it works
- User inputs a message
- A shift value is applied
- Each letter is shifted through the alphabet
- The result can be encoded or decoded

## Purpose
This project was built to practice:
- string manipulation
- functions and modular code design
- basic algorithm thinking
